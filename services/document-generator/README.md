# 私有文件处理服务

该服务只做有边界的文件检查、解析、PPT 模板规范化和 Office 生成，不执行模型脚本，不持有模型或 OSS 凭据。

- `POST /inspect`：base64 文件及实际目标格式，返回受限正文、报告及可用的规范模板。
- `POST /render`：经过 Go Worker 授权和校验的结构化内容及可选模板，返回文件及 hash。
- 写请求需要 `Authorization: Bearer DOCUMENT_GENERATOR_TOKEN`。
- 生产只接内部隔离网络；开发仅绑定 `127.0.0.1:18091`。容器只读、有内存/CPU/PID 限额。
- 本服务不会访问附件中的 URL，不处理宏或 OLE。允许图表所需、通过递归包检查的内嵌 XLSX 数据。
- 个人/企业 PPT 模板保留母版装饰与布局，移除旧幻灯片、备注、批注、缩略图和作者信息。装饰图片仍需上传者检查预览并确认，不承诺任意演示稿无损套版。
- 首版模板需要 16:9，且包含标题和正文占位符；布局不兼容时明确拒绝。
- 无企业模板时，默认PPT按要点密度使用分组卡片或列表，显式设置段落字号和行距；不添加虚构指标或流程顺序。企业模板继续保留原版式。
- Word默认A4中文排版；表格按内容分配列宽，重复表头，并避免同一条记录跨页拆分。模板和复杂长文本仍需实际预览检查。

测试：`python -m unittest discover -s services/document-generator -v`，需安装 `requirements.txt` 中依赖。
