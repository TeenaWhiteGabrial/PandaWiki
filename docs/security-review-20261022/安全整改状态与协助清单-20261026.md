## 四、发布提醒

本次应在备份、确认发布版本后整套升级，不只升级 backend：

```bash
bash deploy/server/deploy.sh upgrade all
```

内部服务新增凭据由脚本生成保存，不需要发送给我。升级后浏览器重新登录；HTTP 明文传输依然需要运维配置 HTTPS。若跨越此前迁移 56 回退，需要升级前数据库及配套服务/配置，不能只换回 API 镜像。详细步骤以[补充修复部署说明](安全补充修复-20261026.md)和既有备份方案为准。
