# 后台任务弹窗分页

后台任务不再调用整棵目录接口。列表、分类数量和完整时间线分别读取：

- `GET /api/v1/node/learning/tasks`：`kb_id`、`filter`、`keyword`、`page`、`page_size`；默认每页 10 条，最大 100 条。返回匹配数量、进行中数量和当前页；越界页自动回到最后一页。
- `GET /api/v1/node/learning/summary`：当前管理员可管理文档的分类数量，独立加载，不阻塞列表显示。
- `GET /api/v1/node/learning/detail`：指定 `kb_id`、`id`，点击“步骤与耗时”后读取完整时间线。
- `GET /api/v1/node/learning/targets`：仅在批量操作时读取整个筛选结果的 ID，包含全部分页。可设置 `only_running=true`；`filter=needs_learning` 对应“学习需处理”。随后仍由原有重建、取消接口再次检查写权限。

所有接口只读取数据库，不触发 RAGLite 查询、重建或队列消费。每次请求重新校验管理范围，不返回文档正文、文件地址、权限展示标签；详细进度也受同样限制。文件夹仅用于生成当前页路径，不作为任务返回。

筛选语义保持原有行为：可问答表示已有成功索引，进行中表示最近任务未结束，两者可以重叠。失败、取消后的旧索引可继续显示可问答。

前端缓存仅保存在当前弹窗组件内，按账号和知识库隔离，最多缓存 20 页。重新打开先显示缓存并重新查询；搜索防抖 300 毫秒；页面或筛选变更中止旧请求，忽略迟到结果。分类统计在 5 秒内可以复用，手动刷新及任务操作后强制更新。

仅保留一套不重叠刷新循环：有进行中任务每 5 秒，无进行中任务每 30 秒。隐藏浏览器页面暂停请求，恢复可见立即查询；关闭弹窗中止请求并停止刷新。任务变更后才通知外层目录刷新。详情仅在打开时读取，进行中任务每 5 秒刷新详情。

## 验证

数据库集成测试使用本地临时 PostgreSQL，事务回滚：

- `TestLearningTaskPagesCountsTargetsAndDetails`：分类一致性、真实分页、路径及原因搜索、批量全部匹配、精简列表与完整详情、历史 NULL 进度。
- `TestLearningTaskPagingKeepsManagementScopeAndBoundedQueries`：2200 份文档、固定查询次数、响应体积、普通管理员范围和权限撤销。
- `node --test web/admin/src/pages/document/hooks/useLearningTasks.test.mjs`：慢统计不阻塞列表、缓存隔离、关闭中止、迟到响应、单一刷新循环和隐藏页面暂停。

本次功能需同时部署 API 和管理端；无需为该功能新增数据迁移，不修改现有后台任务和索引数据。工作区另有安全索引替换改动，若一并发布，仍需遵循其迁移及 API/Consumer 同步升级要求。
